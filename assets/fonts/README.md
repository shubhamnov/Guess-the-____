# Script fonts

Noto Sans fonts from Google Fonts, trimmed to only the characters in the samples in `data/scripts.js`. The Scripts game uses them when a device has no font for a rare script.

They are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). If you change a sample in `data/scripts.js`, download that script's font again with the new text.
